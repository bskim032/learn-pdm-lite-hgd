## 원본에서 뽑은 것

| 구분 | 내용 |
|---|---|
| 오늘의 메시지 | ③ "한 번의 튐(노이즈)이 아니라 추세적 상승이 진짜 신호다. 임계선을 향해 꾸준히 오르는 흐름의 시작점을 잡으면 고장 전 계획 정비가 가능하다." (Main p2) |
| 용어 | 노이즈 = 한 번 튀고 곧 정상으로 돌아오는 일시적 값, 측정 오류·순간 외란일 수 있음 / 추세 = 임계선을 향해 꾸준히 오르는 흐름, 시작점이 정비 신호 (Main p14) |
| 실습 단계 | ④ 분석 1 — 이상 후보가 노이즈인지 추세인지 구분, 추세 시작 시점을 "정비 필요 시점"으로, 시간축 + 변수 + 임계선 선 차트 (Main p20) |
| 실습과제 · 모범답안 | 실습과제 2: [1.0→1.1→0.9→3.5→1.0] vs [1.0→1.3→1.7→2.2→2.9] 중 정비 신호는? 정답 두 번째. 감점: "한 번 높았으니 위험"은 노이즈와 추세 혼동 (Main p25·p27) |
| 판정 규칙 | 설비별 처음 12점(08:00~11:40) 기준선 평균 + 3σ = 상한, 3번 연속 넘으면 추세(첫 점 = 추세 시작), 연속 3번 미만이면 노이즈 (learn-auto-pdm block3) |
| 정답 수치 (정답 메모) | 설비A 진동 3.5(12:40) 한 점 = 노이즈형 / 설비B 추세형, 14~20번째 완만한 상승은 ±2σ에 안 잡힘 (`data/_강사용_정답메모.md` Day5) |

## 가정과 확인 필요
- 짝 점검표(STEP 8)의 "추세 시작 13:00"은 설비B **온도** 기준이다. 진동만 보면 15:00이다 → 그래프에 설비B 온도를 함께 넣을지 승인 ①에서 확인.
- 원본 덱의 평상 범위는 평균 ± 2σ(Main p19)이고, 추세 판정 규칙(기준선 + 3σ, 3번 연속)은 보충교재 learn-auto-pdm에서 가져왔다.
