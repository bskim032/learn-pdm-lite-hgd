| 항목 | 값 |

## EXECUTE

Phase A 출력 직전에 `{SKILL_DIR}`를 이 스킬 폴더의 실제 경로로 바꿔 보여 준다.

```
예지보전 실습판 준비를 해 줘.
1. 내 홈 폴더에 kma-pdm-lite 폴더를 만들고, 그 안에 data 폴더를 만들어
   {SKILL_DIR}/assets/lab 안의 csv 파일과 README.md를 복사해 줘.
2. Python 3가 있는지 확인하고 없으면 설치해 줘.
3. data의 csv 행 수와 첫 줄(열 이름)을 보여 주고,
   설비별 행 수와 단위(mm/s·℃·bar)가 열 이름에 있는지 확인해 줘.
4. 결과를 kma-pdm-lite/env_check.txt 에 항목마다 OK / 조치 필요로 적어 줘.
하지 말 것: data 원본 파일을 고치지 않는다.
```

### 확인할 것 (Phase B)

`~/kma-pdm-lite/env_check.txt`와 `data/`를 직접 읽어 확인한다.

- `data/Day5_설비센서_50건_가상.csv` 50행 — 설비A 25행 · 설비B 25행
- 열 이름에 진동(mm/s)·온도(℃)·압력(bar) 단위가 있다
- Python 3가 OK

막히면 "방금 오류의 원인과 해결을 한 줄씩 설명한 뒤 고쳐 줘"를 붙여 넣게 한다.
